# ⚡ Piyush Refurbished — Certified Pre-Owned Laptops & MacBooks Store

India's premier certified refurbished laptop and e-commerce platform built with **Next.js 13 (App Router)**, **TypeScript**, **Tailwind CSS**, **Prisma**, **Clerk Authentication**, and **Stripe**.

---

## 📁 Repository Structure

- [`/ecommerce-store`](./ecommerce-store): Customer-facing e-commerce storefront with Indian pricing (INR ₹), 1-Year Pan-India warranty guarantees, GST input invoice benefits, and No-Cost EMI indicators.
- [`/ecommerce-admin`](./ecommerce-admin): Multi-store CMS & Admin dashboard to manage products, categories, orders, billboards, colors, and sizes.

---

## 🚀 Getting Started

### 1. Storefront (`ecommerce-store`)
```bash
cd ecommerce-store
npm install
npm run dev -- -p 3001
```
Visit: `http://localhost:3001`

### 2. Admin CMS (`ecommerce-admin`)
```bash
cd ecommerce-admin
npm install
npm run dev -- -p 3002
```
Visit: `http://localhost:3002`

## 🛠️ Tech Stack
- **Framework:** Next.js 13 (App Router), React, TypeScript
- **Styling:** Tailwind CSS, Lucide Icons, Headless UI
- **Database & ORM:** PostgreSQL / MySQL, Prisma ORM
- **Authentication:** Clerk Auth
- **State Management:** Zustand
- **Payments:** Stripe / UPI Ready
